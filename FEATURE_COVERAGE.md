## Evidence

- Desktop baseline: 860 Domain + 966 Engine + 7 original park integration tests.
- Expanded workflow/animation harness: 71/71 passed on desktop and both ARM64 devices, including QR formats, shared audits, catalogue persistence and travel animations. Full desktop suite: 1,898 tests.
- Offline data harness: all nine bundled dex generations and six event archives work on both handhelds; Gen 3/9 generation reports legal results.
- Native UI proof on both devices: `MON → A`, every unrelated slot unchanged, pre-edit and pre-restore backups verified, restored file byte-identical to the original.
- Actual process-termination recovery: 16/16 cases per device across two-save/Bank transactions; no live saves used.
- Android: full project compilation passed after installing the required workload/platform and delegating editor mutations to the shared application workflow. Recheck after further shared changes.
- ROCKNIX GPU framebuffer screenshots can read back black although the screen is correct. Compositor captures confirmed Home rendering; use `grim` when collecting RGDS visual evidence.

The release gate stays open until the action inventory and every applicable acceptance item have an explained, verified result.
